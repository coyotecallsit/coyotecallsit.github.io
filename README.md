# Coyote Calls

Live at **https://coyotecallsit.github.io/**

NFL hub: 500,000-game simulations for every game of the week, model leans, best bets, player-prop looks, a prop calculator, top-100 players, team histories and sim videos. Every pick is logged before kickoff and graded automatically on the Track record tab.

The site is one self-contained page (`index.html`, with all data built in) plus the `videos/` folder, rebuilt automatically every morning and again on game days.

Player stats and injury reports: nflverse (CC BY 4.0). Not betting advice. 21+. If you or someone you know has a gambling problem, call 1-800-GAMBLER.
